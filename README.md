# FOC---Digital-Clock
# ⏰ Digital Clock

A simple digital clock created as a single HTML file. The application displays the current system time in **HH:MM:SS** format and updates automatically every second.

## ✨ Features

- ⏰ Real-time digital clock
- 🔄 Automatic time updates every second
- 📄 Single-file implementation
- 🚀 No installation or dependencies required
- 🌐 Runs directly in any modern web browser

## 📂 Project Structure

```
Digital-Clock/
│── index.html
│── README.md
```

## 🚀 How to Use

1. Download or clone the repository.
2. Open `index.html` in your preferred web browser.

No setup or installation is required.

## 📖 Overview

This project demonstrates how a fully functional digital clock can be implemented within a single HTML file, making it lightweight, portable, and easy to understand for beginners.
