# ⏰ Digital Clock

A simple and lightweight **Digital Clock** built using a single HTML file with embedded CSS and JavaScript. The clock displays the current system time in **HH:MM:SS** format and updates automatically every second.

## ✨ Features

- ⏰ Displays the current system time
- 🔄 Updates every second in real time
- 🎨 Clean and minimal user interface
- 📱 Responsive and centered layout
- 📄 Built entirely in a single HTML file
- ⚡ No external libraries or frameworks required

## 🛠️ Technologies Used

- HTML5
- CSS3 (Embedded)
- JavaScript (Embedded)

## 🚀 How to Run

1. Download or clone the repository.

```bash
git clone https://github.com/your-username/Digital-Clock.git
```

2. Open the `index.html` file in any modern web browser.

That's it! No installation, dependencies, or setup is required.

## 📖 How It Works

- JavaScript uses the `Date()` object to retrieve the current system time.
- The time is formatted into **HH:MM:SS**.
- The display updates every second using `setInterval()`.
- CSS is embedded within the HTML file to create a clean, centered interface.
